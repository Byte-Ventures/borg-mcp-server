Reliable Coordination makes log posting and reconnect recovery safe to retry.

- Every log post carries a caller-generated UUID. An exact retry by the same author returns the original entry with `deduplicated: true` instead of creating a duplicate.
- Reusing a post UUID with changed content or resolved routing returns `POST_ID_CONFLICT` without exposing an entry or sending another event or wake.
- Different authors may independently use the same UUID.
- A fresh attachment returns the cube-head log cursor captured with the new session, and retries return that same persisted cursor.
