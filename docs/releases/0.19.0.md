Managed service installation now provides an explicit, loopback-only background-service path for prepared local servers.

- `borg-mcp-server service install [--json]` installs and starts an owner-scoped launchd agent on macOS or systemd user service on Linux, with idempotent retries and bounded machine-readable results.
- `borg-mcp-server start` remains foreground-only and stops with Ctrl-C. The public `stop` command and service API were removed; later managed-service control uses the platform service manager.
- Setup offers managed installation only for loopback configurations. Private-LAN configurations remain foreground-only and require explicit `--lan` consent when started.
- Installation verifies initialized data and the prepared runtime, rejects foreign or unsafe definitions and log sinks, preserves strict single-link ownership boundaries, and reports rollback as restored only when the prior stable runtime identity returns.
- Published markerless `borgmcp-server@0.18.1` service definitions remain replaceable only when they match the exact generated legacy shape; arbitrary unmarked definitions remain untouched.
