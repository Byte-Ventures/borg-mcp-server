Protocol v10 adds immutable, cube-scoped text documents for coordination
artifacts. Documents support linear revisions, author-or-manager removal,
audit-retained exact-id reads, active byte budgets, and structured activity-log
citations whose metadata follows the document's current state.

Activity messages now carry document-storage guidance above 1 KiB and reject
messages above 4 KiB by default. Large authenticated document uploads are
admitted only after authentication, and document relations are structurally
cube-scoped in SQLite.
