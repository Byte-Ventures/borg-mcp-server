This release adds the protocol v11 acknowledgement-status read surface.

- The server now consumes `borgmcp-shared@0.14.0` and exposes strict acknowledgement-status request and response contracts.
- Authenticated cube readers can inspect intended recipients, nullable acknowledgement timestamps, and separate advisory claims for an activity entry without consuming unread activity.
- Unknown, pruned, unauthorized, and cross-cube activity entries retain the existing non-enumerating `NOT_FOUND` refusal.
