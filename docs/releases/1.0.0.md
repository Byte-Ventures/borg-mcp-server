# borgmcp-server 1.0.0

- Moves the server to protocol v12 and exact `borgmcp-shared@1.0.0`.
- Requires every log append to provide explicit `to: "broadcast"` or a non-empty recipient-selector array. Legacy public visibility and resolved-recipient inputs are rejected.
- Makes message taxonomy classification-only by removing stored routing defaults while preserving message history, delivery visibility, recipients, unread state, acknowledgements, claims, streams, wakes, and cursors.
- Adds read-only exact or eight-hex-prefix activity entry lookup with scoped not-found behavior and explicit ambiguity rejection.

This is a breaking protocol release. Protocol-v11 and earlier clients cannot coordinate with this server.
