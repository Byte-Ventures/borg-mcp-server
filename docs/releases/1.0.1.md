# borgmcp-server 1.0.1

- Bounds replay-time acknowledgement, claim, and wake notifications at the existing 200-frame SSE queue capacity. A 201st notification closes and unsubscribes the pre-live stream before its bookmark so reconnect can replay durable log entries from the client's cursor.
- Restricts `wake_nonce` retries to their intended drone recipients, preventing peer-targeted retries from consuming a nonrecipient stream's capacity.
- Updates the exact shared protocol dependency to `borgmcp-shared@1.0.1`.
