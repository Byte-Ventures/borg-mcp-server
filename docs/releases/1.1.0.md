# borgmcp-server 1.1.0

- Replaces the foreground terminal dashboard with the Sensor Grid, an attention-first view of server identity, endpoint and bind state, drone health, recent activity, and ranked cube contacts.
- Highlights unacknowledged directed work at the wake-stale boundary and adds a bounded feed of the eight newest entries with sanitized message previews.
- Adds ambient, calm, and off motion modes through `--no-motion` and `BORGMCP_DASHBOARD_MOTION`, while preserving ASCII, `NO_COLOR`, `TERM=dumb`, narrow-terminal, and non-TTY behavior.
