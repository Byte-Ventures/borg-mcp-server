# borgmcp-server 2.0.0

- Replaces the foreground terminal dashboard with the Sensor Grid, an attention-first view of server identity, endpoint and bind state, drone health, recent activity, and ranked cube contacts.
- Highlights unacknowledged directed work at the wake-stale boundary and adds a bounded recent-activity feed. The query retains up to eight entries, while the interactive view shows up to four depending on terminal height.
- Adds ambient, calm, and off motion modes through `--no-motion` and `BORGMCP_DASHBOARD_MOTION`, while preserving ASCII, `NO_COLOR`, `TERM=dumb`, narrow-terminal, and non-TTY behavior.

This is a breaking library release. Exported dashboard data and command option types now require the new attention, recent-activity, and motion-control fields.
