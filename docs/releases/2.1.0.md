# borgmcp-server 2.1.0

- Replaces per-drone activity tickers with a shared Sensor Scope that shows aggregate activity magnitude and timing in one view.
- Adds an attention-first compact drone board that prioritizes stale and unacknowledged targets while retaining status, name, and age at the supported 40x10 boundary.
- Preserves responsive wide, stacked, and compact layouts together with ASCII, `NO_COLOR`, and motion-off presentation modes.
- Keeps constrained embedded dashboards explicit that stopping the server leaves saved data and identity intact and that the dashboard is read-only.
- Stabilizes release artifact validation by assigning synthetic npm publish dry-runs a non-latest distribution tag.
