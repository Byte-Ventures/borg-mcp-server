# borgmcp-server 3.0.0

- Introduces the Nightwatch dashboard with an explicit near-black palette, deterministic color-depth fallbacks, and complete terminal restoration across embedded and standalone views.
- Quantizes the shared Sensor Scope into stable aggregate time buckets with bottom-filled bars, observed-versus-missing coverage, and a non-destructive sweep.
- Adds fixed drone-table columns for status, attention, identity, role, reported model, sent count, and age while preserving the compact 40x10 priority and lifecycle contract.
- Keeps `NO_COLOR`, strict ASCII, `TERM=dumb`, non-TTY, and plain fallback output free of styling escapes and forced backgrounds.
- **Breaking:** `DashboardDroneData.reported_model` is now required as `string | null`. Custom `DashboardSnapshotSource` implementations and callers constructing `DashboardDataSnapshot` values must provide this field for every drone; use `null` when no model was reported.
