# borgmcp-server 3.1.0

- Returns bounded field-level message-taxonomy validation detail to manage-scoped callers while read-scoped callers continue to receive no field detail.
- Refuses a new attachment to an occupied human-seat role with `ROLE_IN_USE` and names the current holder; matching credential reuse and replacement after eviction remain available.
- Stops enrollment before credential exchange when a request aborts during body reading, preventing a handler deadline or client disconnect from leaving a live credential after the operator receives a 503 or no response.
