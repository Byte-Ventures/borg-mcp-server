# borgmcp-server 3.2.1

- Adds structured runtime latency logging on stderr: authenticated requests report method, normalized route, status, and elapsed time, with a separate slow-request line at >= 1 second. Liveness scans report timing, append operations report append and prune timing, and activity reads report result size and enrichment counts. This work is tracked in [#371](https://github.com/Byte-Ventures/borg-mcp-server/issues/371).
- Gates per-request runtime log emission on accepted authentication, so unauthenticated traffic cannot grow the log.
- This release changes no request behavior. The stderr sink's lack of rotation predates this release and is tracked separately in [#373](https://github.com/Byte-Ventures/borg-mcp-server/issues/373).
