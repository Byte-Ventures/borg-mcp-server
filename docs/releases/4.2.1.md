# borgmcp-server 4.2.1

Updates built-in agent guidance to use the canonical underscore MCP tool names,
including `borg_update_cube`, `borg_put_document`, and `borg_remove_decision`.
These names work as JavaScript properties in OpenCode 2 Code Mode.

Consumes `borgmcp-shared` 2.2.1 so built-in role templates and server guidance
agree with the coordinated client release. Upgrade the client to 7.0.0 when
adopting this tool catalog. Existing saved roles are preserved; authorization,
stored data, migrations, and protocol version 14 retain their current behavior.

Updates development test dependencies to address dependency audit findings.
